A code browser for Ruby on Rails

Runs on Omarchy Linux Works on macOS too

Rubyscope is not an IDE and not an editor. It is a small desktop app for browsing Ruby and Rails code. Hold Ctrl and click a class, a method, a route helper, a translation key or a partial. It opens where that thing is written. Built in Rust, for Omarchy Linux and macOS.

Go to definition that knows Rails

A text search finds every ship! in the project. Rubyscope finds the one you mean. It follows Ruby's lookup rules and the conventions of Rails, RSpec, FactoryBot and Stimulus.

Methods, and the type behind them

Rest the pointer on a name to see its signature, its docs and where it is defined. The popup also says how Rubyscope found the type: exact, inferred, a guess, or by name only.

  • Method lookup in Ruby's order: prepends, the class, includes, the superclass
  • Concerns, class_methods, delegate, super
  • Associations, scopes, enums and columns from db/schema.rb

From a controller action to its view, and back

Ctrl+click the name of an action to open its template or Phlex view. A view shows a link to its action above the code, so the way back is one click too.

  • ERB templates, Phlex views and variant folders
  • Mailer methods and their templates
  • The right-click menu has "Go to view" and "Go to controller action"

Translation keys and route helpers

A click on t(".updated") opens the line in the locale file, in every locale. Lazy keys work in controllers, templates and Phlex views. A route helper such as order_path opens the line in the routes file.

  • render "orders/line_item" opens the partial
  • resources :orders opens the controller
  • data-action="order#ship" opens the Stimulus method

Who uses this?

Ctrl+click a class name where it is defined, and the results panel lists every place that uses it. For a method, right-click and choose "Find usages". The "callers" button on a row goes one level up the call stack.

When a name means several things

Some calls have no known receiver, such as a method on a block argument. Rubyscope then lists every definition with that name, and says how sure it is about each one. It never guesses in silence.

Git blame next to the code

Press Ctrl B, or click Blame in the top bar. Each line shows the date and the author, and newer lines get a stronger blue. Click a block to open the commit, or its pull request, on GitHub.

Read a branch like a pull request

Press Ctrl Shift D, or click Diff. Lines your branch added are green, removed lines show as red rows between the real lines, and changes that are not committed yet are amber. The code is still the real file, so Ctrl+click and the hover keep working.

  • The diff starts where your branch left main, as on GitHub
  • ] and [ go from change to change, and on to the next changed file
  • The file tree opens the folders with changes, and a Changes tab lists them

Pull and switch branches from the top bar

The round arrow runs git pull in the background. The button with the branch name lists the branches, the newest first, with the initials of the pull request author. Pick one to switch. Rubyscope reads the open files again and updates the index.

  • On conflicts it names the files and fixes nothing
  • It also follows a switch made in the terminal
  • The top bar shows how much RAM Rubyscope uses

Dark or light

The sun and moon button at the right end of the top bar switches between dark and light, and Rubyscope keeps your choice. On Omarchy it uses the colors of your theme when the theme is of the same mode. Otherwise it uses Tokyo Night or Tokyo Night Day.

Your projects, one key away

The start screen lists your projects as numbered cards. Press a number to open that project, or drag a card to change its number. The "…" button renames a project in the list or removes it. A project shows its own icon when it has one.

Keys for everything

Ctrl P finds a file. Ctrl T finds a class, method or constant in the project and its gems. Ctrl K lists every command. Ctrl Shift D turns diff mode on, and ] and [ go from change to change. Scroll with j and k, and go to the top with gg, as in Vim. Every key can be changed in one small file.

What a click understands

Rubyscope reads the source. It does not boot Rails or run your code, so it works on an app that does not start.

Constants
Lexical scopes, ancestors, class A::B, constant aliases and Zeitwerk folder namespaces.
Methods
class << self, extend, module_function, class_eval, ActiveSupport.on_load.
Rails DSLs
Associations, scopes, enums, delegate, attribute, store_accessor, attachments, schema columns.
Symbols that name methods
before_action :load, validate :check, if: :paid?, send(:x).
Variable types
Model.find, relations, block parameters, instance variables, YARD @return, FactoryBot create(:x).
Views
Controller actions and views both ways, partials, Phlex kit calls, and Ruby inside ERB tags.
Routes and locales
Route helpers, resources, to: "a#b", and t("a.b") keys in every locale file.
Tests
RSpec let, subject, described_class, shared examples, factories and traits.
Gems
Every gem in Gemfile.lock that is installed, and the Ruby standard library.

Fast on a large app, and safe to leave open

About one second to start

Rubyscope parses every Ruby file with Prism, on all CPU cores, and saves the index. The next start reads the saved index and parses only the files that changed.

Stays up to date

A file watcher sees changes in app, config, db, lib and the specs. Open tabs load the new text and the index updates itself.

Reads only

Rubyscope never writes into your project. To change a file, open it in your editor from the right-click menu, at the same line.

Install

Rubyscope is built from source with Rust 1.88 or newer, clang and libclang.

Linux

git clone https://github.com/equivalent/rubyscope
cd rubyscope
bin/install
rubyscope ~/code/shop

Installs the app in ~/.local/bin with an app launcher entry. Built and used on Omarchy, on Wayland.

macOS

git clone https://github.com/equivalent/rubyscope
cd rubyscope
bin/install-macos
rubyscope ~/code/shop

Installs rubyscope.app in ~/Applications. Runs on Apple silicon. Use Cmd where the docs say Ctrl.
